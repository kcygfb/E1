# 回合对战设计文档

更新时间：2026-08-04
当前阶段：统一战斗流架构已接入。

## 1. 核心规则

| 规则 | 当前实现 |
|---|---|
| 初始牌组 | 15 张 |
| 玩家每回合行动点 | 3 |
| 玩家每回合抽牌 | 4 张 |
| 手牌上限 | 10 张 |
| 初始/最大魔法 | 3/3 |
| 每回合最多耗蓝 | 1 |
| 自动大招 | 累计耗蓝 3 点，造成 30 点并回满魔法 |
| 处决 | 敌人韧性击破时自动造成大量伤害并眩晕 1 回合 |
| 玩家/敌人效果 | 共用 CombatFlowController |
| 战败闭环 | 未实现 |

## 2. 战斗单位与行动来源

玩家和敌人都使用 `CombatantState`，拥有生命、韧性、行动点和状态。

区别只在行动来源：

- 玩家由输入系统产生 `CombatActionIntent`；
- 敌人由 AI 产生 `CombatActionIntent`；
- 大招、处决和状态 tick 由系统产生结算。

Intent 进入 `CombatEngine` 后，双方共用同一个 `CombatFlowController`。AI 和 UI 都不能直接修改生命或状态。

## 3. 牌组与 JSON

Manifest 管理 7 个分类、54 个定义和 76 份 copies：

- 玩家：42 个定义/64 份；
- 敌人：12 个定义/12 份；
- 敌人类型：Dog、LittleGirl、BigEye。

Manifest 为 ASCII 安全 JSON，中文来源字段使用 Unicode 转义。Repository 已完整加载验证。

玩家初始牌组必须恰好 15 张。玩家和每个敌人分别拥有抽牌堆、手牌和弃牌堆。

## 4. 玩家回合开始

1. 回合数加 1。
2. 重置玩家本回合耗蓝额度。
3. 推进玩家的回合持续状态。
4. 结算玩家流血/中毒并检查失败。
5. 结算敌人流血/中毒并检查胜利。
6. 检查玩家眩晕或敌方施加的跳过：
   - 命中时玩家整个回合跳过；
   - 不抽牌；
   - 不恢复行动点；
   - 直接进入敌方回合。
7. 未跳过时恢复 3 点行动点。
8. 抽 4 张牌。
9. 进入玩家输入阶段。

## 5. 玩家出牌

1. UI 构造玩家 Intent。
2. 引擎验证玩家控制权、阶段、手牌、目标和费用。
3. 支付行动点或魔法。
4. 进入统一效果流。
5. 中枢处理攻击无效、减伤、格挡、效果、死亡与反伤。
6. 若玩家击破敌人韧性：
   - 自动追加大量伤害（处决）；
   - 处决未击杀则眩晕目标 1 回合；
   - 存活目标恢复韧性。
7. 卡牌弃置并清除本次强化。
8. 耗蓝牌检查自动大招。
9. 检查胜负并回到玩家输入。

## 6. 敌方回合

敌人抽牌在**玩家回合开始时**统一进行（`CombatEngine.BeginPlayerTurn`），因此玩家在自己的回合就能看到敌人将出的牌（顶部常驻展示），可以见招拆招。

玩家结束回合后：

1. 弃掉未使用的玩家手牌。
2. 检查玩家施加的敌方整回合跳过。
3. 推进每个敌人的回合持续状态。
4. 重置敌人出牌计数。
5. 按定义恢复敌人行动点。
6. AI 开始行动（使用玩家回合已抽好的手牌，不再重复抽牌）。

每个敌人第一次行动时经过授权闸门：

- 当前敌方整体回合是否跳过；
- 该敌人是否被眩晕；
- 该敌人是否已经在本回合被阻止；
- 通过后标记为本回合已授权。

因此普通卡、特殊卡、固定攻击或外部直接调用都不能绕过眩晕和跳过。

AI 只负责：

- 选择哪张牌（手牌由玩家回合统一抽好）；
- 是否使用特殊牌；
- 何时结束回合。

实际费用、伤害和效果由统一中枢处理。

## 7. 效果结算

### 敌对效果

- 伤害与多段伤害；
- 韧性伤害；
- 眩晕；
- 流血；
- 中毒；
- 易伤；
- 两种吸血；
- 按流血层数造成伤害。

### 自身效果

- 格挡；
- 减伤；
- 攻击无效次数；
- 反伤；
- 抽牌；
- 获得行动点；
- 跳过对手回合。

混合卡牌可以同时对对手造成伤害，并给发起者增加防御状态。

### 统一伤害顺序

1. 攻击无效（按整个行动）；
2. 目标百分比减伤；
3. 目标格挡；
4. 扣除实际生命；
5. 死亡事件；
6. 整个敌对行动结束后处理反伤。

状态 tick 不使用普通攻击的格挡/减伤路径。

## 8. 流血与中毒

玩家和敌人在玩家回合开始时统一 tick：

- 当前层数 x 造成 x 点伤害；
- 结算后层数减 1；
- 可以导致胜利或失败。

当前中毒公式仍与流程图“固定 25 点/回合”不同，是否修改以后单独决定。

## 9. 魔法、强化与大招

- 玩家魔法跨回合保留；
- 每回合最多消耗 1 点；
- 强化与魔法牌共享额度；
- 强化指定卡牌实例，使用/弃牌后清除；
- 累计耗蓝 3 点触发大招；
- 大招通过统一伤害流造成 30 点；
- 大招后魔法恢复到 3；
- 大招不眩晕。

敌人目前不使用魔法资源。

## 10. 处决

处决由统一流在玩家击破敌人韧性时触发：

- 自动造成大量伤害（当前 60 点）；
- 不等待确认；
- 处决未击杀时，目标眩晕 1 回合（停止行动）；
- 小兵、精英、Boss 使用相同伤害；
- 存活目标恢复韧性；
- 冲击钻（Hydraulic Breaker）等 `execution_double` 效果可将下次处决伤害翻倍（一次性消耗）。

敌人击破玩家韧性不会触发处决。

## 11. 胜负

- 玩家死亡：失败；
- 所有敌人死亡：胜利；
- 每次状态、卡牌、固定攻击、大招和处决结算后统一检查。

胜利已有奖励流程。失败仍缺少弹窗、重试、返回与转场。
